
## Ритм работы

### Сессии
- Одна сессия — одна цель с проверяемым критерием готовности.
- Начало: `/start` — прочитать docs/STATUS.md «Следующая сессия», предложить план.
- Конец: `/finish` — обновить STATUS.md и DECISIONS.md.
- Решение по ходу работы — сразу `/decision <суть>`.
- Долгое состояние хранится в файлах (SPEC, DECISIONS, STATUS), не в истории диалога.
- Новая цель — `/clear`; длинная сессия с той же целью — `/compact`.

### Большие задачи
- Постановка — файл TASK.md по шаблону docs/TASK_TEMPLATE.md, запуск — `/task`.
- Сначала режим планирования; код — только после утверждения плана.
- Если ушло не туда — откат к контрольной точке, а не «исправь обратно».

### Проверка
- После крупного этапа — `/audit` (независимый подагент reviewer).
- Раз в неделю и в конце этапа — `/verify` (сверка docs/ с кодом).

### Особенности этого репозитория
- Источник истины по товарам — Google Sheets (лист «Товары») через sheets-unified-api.gs, не код.
- catalog.html — главная сайта (build.sh копирует её в index.html), sourdough-shop.html — оформление
  заказа и чат ИИ: обе не трогать без явного решения.
- Адреса API подставляет website/build.sh (safe_replace) — не хардкодить их в страницах.


## Инварианты — не нарушать
- Источник истины по товарам — Google Sheets, лист «Товары», через sheets-unified-api.gs.
  Не дублировать данные товаров в коде.
- catalog.html (главная, открывается по корню домена) и sourdough-shop.html (оформление заказа).
  Любая правка — только после явного «да» владельца: остановись и спроси. Защищено хуком guard.py,
  разрешение — запуск с ALLOW_MAIN_EDIT=1.
- Ключ ANTHROPIC_API_KEY — только в Environment сервиса sourdough-bakery-bot на Render. В страницах, коде
  и репозитории его нет; чат сайта ходит через /api/ask-faq бота. Ключи Anthropic в правках блокирует guard.py.
- Адреса API в страницах — только плейсхолдеры BOT_API_URL / REVIEWS_API_URL / ORDERS_API_URL,
  их подставляет website/build.sh (safe_replace). Защищено хуком guard.py.

## Защита
- Запрещены git push, чтение и правка .env, ключей и секретов (settings.json). Push — только владелец.
- Если хук отказал — не обходить другим путём (например, через shell). Сделай так, как написано
  в сообщении хука, или спроси.
